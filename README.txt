POST COMPOSER - REACT

How to run:

1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open the terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost URL shown in the terminal.

Features:
- Twitter and LinkedIn selection
- Twitter limit: 280 characters
- LinkedIn limit: 3000 characters
- Live character count
- Error message when the limit is exceeded
- React controlled textarea using useState
